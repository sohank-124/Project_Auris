# Component inventory

The canonical inventory is [hardware/bom/bom.csv](../../hardware/bom/bom.csv), with [inventory
qualifications](../../hardware/bom/README.md). Part identifiers and supplier fields are historical references, not
verified purchase records, live availability, exact breakout schematics, or substitution approval.

Actual breakout identity and the headphone output stage must be recorded during [hardware
validation](HARDWARE_VALIDATION.md).
